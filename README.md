# Fragrance-Formulation-Quiz-Game
Python command-line game that scores fragrance blends the player creates. 
A command-line Python game that scores fragrance blends for Summer, Winter, and Date profiles. Choose ingredients from a catalogue of 75+ notes, and the program averages their suitability scores (0-10) to decide if your blend passes.

## How to run
python main.py

## Files
- main.py: game loop and scoring
- ingredientdict.py: ingredient catalogue with scent descriptions
- SUMMERdict.py, WINTERdict.py, DATEdict.py: suitability scores per profile
